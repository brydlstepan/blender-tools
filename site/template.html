Blender Tools

Viewport tools for Blender 5.2+: absolute transform, clear parent, separate FBX export, Unreal import.

Add-on

Install Blender Tools into Blender 5.2 or newer.

Drag and Drop into Blender

...or download and Install from Disk

If you drag & drop into Blender you will need to do it twice. First to add this repository, secondly to install the add-on itself. This method lets you receive update notifications whenever a new version of the add-on is available.

Get updates inside Blender

Preferences → Get Extensions → Repositories → + → Add Remote Repository, then paste the repository link: copy the address of this page and add index.json at the end.
