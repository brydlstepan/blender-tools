Blender Tools

Viewport tools for Blender 5.2+: absolute transform, clear parent, separate FBX export, Unreal import.

Install

  1. Open Blender 5.2 or newer.
  2. Drag the extension link below onto the Blender window.
  3. Confirm the install and enable Blender Tools.
${body}

Get updates inside Blender

Preferences → Get Extensions → Repositories → + → Add Remote Repository, then paste the repository link: copy the address of this page and add index.json at the end.
